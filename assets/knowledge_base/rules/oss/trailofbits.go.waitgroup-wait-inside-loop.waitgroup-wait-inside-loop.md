**Rule.** Calling `$WG.Wait()` inside a loop blocks the call to `$WG.Done()`

**Why.** Reported as CWE-667: Improper Locking. See https://go101.org/article/concurrent-common-mistakes.html. Ported from opengrep rule `trailofbits.go.waitgroup-wait-inside-loop.waitgroup-wait-inside-loop` (generated/oss/vulns.yaml).

## Examples

Bad:

```go
var $WG sync.WaitGroup
...
for ... {
  ...
  go func(...){
    ...
    defer $WG.Done()
    ...
  }()
  ...
  $WG.Wait()
  ...
}
$WG := &sync.WaitGroup{}
...
for ... {
  ...
  go func(...){
    ...
    defer $WG.Done()
    ...
  }()
  ...
  $WG.Wait()
  ...
}
```
