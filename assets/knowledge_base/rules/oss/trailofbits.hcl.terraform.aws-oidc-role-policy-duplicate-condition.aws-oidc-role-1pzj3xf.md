**Rule.** Found AWS role policy for GitHub Actions with duplicate condition. This overrides previous conditions, and the last condition with the duplicated key "wins." This likely breaks access controls and allows unauthorized access.

**Why.** Reported as CWE-284: Improper Access Control. See https://securitylabs.datadoghq.com/articles/exploring-github-to-aws-keyless-authentication-flaws/. See https://www.rezonate.io/blog/github-misconfigurations-put-gcp-aws-in-account-takeover-risk. See https://github.com/Rezonate-io/github-oidc-checker/. Ported from opengrep rule `trailofbits.hcl.terraform.aws-oidc-role-policy-duplicate-condition.aws-oidc-role-policy-duplicate-condition` (generated/oss/audit.yaml).
