**Rule.** Found AWS role policy for GitHub Actions missing OIDC subject. This means any GitHub repository can assume this role in CI.

**Why.** Reported as CWE-284: Improper Access Control. See https://securitylabs.datadoghq.com/articles/exploring-github-to-aws-keyless-authentication-flaws/. See https://www.rezonate.io/blog/github-misconfigurations-put-gcp-aws-in-account-takeover-risk. See https://github.com/Rezonate-io/github-oidc-checker/. Ported from opengrep rule `trailofbits.hcl.terraform.aws-oidc-role-policy-missing-sub.aws-oidc-role-policy-missing-sub` (generated/oss/audit.yaml).

## Examples

Bad:

```text
{
  ...
  "Condition": {
      ...
      "StringEquals": {
          ...
          "token.actions.githubusercontent.com:aud": ...,
          ...
      }
      ...
  }
  ...
}
```

Good:

```text
{
  ...
  "Condition": {
      ...
      "StringEquals": {
          ...
          "token.actions.githubusercontent.com:sub": ...,
          ...
          "token.actions.githubusercontent.com:aud": ...,
          ...
      }
      ...
  }
  ...
}
{
  ...
  "Condition": {
      ...
      "StringEquals": {
          ...
          "token.actions.githubusercontent.com:aud": ...,

          "token.actions.githubusercontent.com:sub": ...,
          ...

      ...

  ...
}
{
  ...
  "Condition": {
      ...
      "StringLike": {

          "token.actions.githubusercontent.com:sub": ...,
          ...
      }

      "StringEquals": {
          ...
          "token.actions.githubusercontent.com:aud": ...,
          ...

      ...

  ...
```
